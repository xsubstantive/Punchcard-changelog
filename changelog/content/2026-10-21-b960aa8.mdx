- **Spot client uploads more easily.** New-file indicators identify client uploads, and the undownloaded count appears as a badge beside the file section title.

- **Upload more file types.** Uploads accept any file type, and macro-enabled Excel workbooks can be read as spreadsheets.

- **Keep every file in a download.** Files with identical names are retained in ZIP downloads with numbered names.

- **Safer Excel work with CoAudit.** Supporting formulas are better protected, interrupted work recovers more reliably, and busy Excel windows are handled more gracefully.

- **Answer CoAudit questions in place.** Questions remain visible above the composer until answered, and draft answers survive the question moving within the pane.

- **A clearer Financial Statement Review start.** Guided setup starts with the prior-year statement and better protects existing review work.

- **Filter engagement activity.** Grouped activity filters let you select several related activity types together.

- **Configure Benford sampling.** Choose leading-digit settings and filter Benford sampling results.

- **Enter audit functions in worksheet cells.** Use Punchcard custom functions by typing them directly into Excel.
