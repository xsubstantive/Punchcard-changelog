## Improvements

- **Simpler Request selection for agent tasks:** Choosing which Requests an agent task reads from or acts on is now a single option, such as "Triggering request and subrequests". You can narrow it down to specific details, documents, or comments when you need to.
- **Clearer wording:** Labels now name the Requests first (for example, "Triggering request · documents"). They say "Triggering requests" when a trigger covers several Requests. Presets such as Workpaper first draft, Auto-sort, and Client validation use the same wording.
- **Search in Triggers:** The Triggers tab has a search box next to the create button, so you can find a trigger quickly in a long list. Inputs, Actions, and Outputs now sit under each trigger's name.
- **Run results open in place:** Comments and files from an agent task run open the Request or task in the side pane, at the exact comment or file. You no longer leave the tab. Files saved into an engagement folder are listed too and open in the Files tab at that folder.
- **Clearer file upload feedback:** When an older Word file is converted during upload, the file feedback now explains what happened.

## Fixes

- **Comment editing:** Editing in the middle of a comment now keeps your cursor where you put it. Before, the cursor could jump to the end when the thread updated while you typed.
- **Financial Statement Review:** The review card's "Open review" link now always opens the review for the task shown. Before, it could open a different task's review after you switched between tasks in the engagement list.
