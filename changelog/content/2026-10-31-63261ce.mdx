- **Import a request hierarchy.** Numbered rows such as 3.1 import as sub-requests of request 3.

- **Keep selecting cells in Excel.** An unanswered selection read no longer freezes subsequent cell clicks.

- **Find External Review by name.** The read-only workbook review setting is now called External Review.

- **Calmer success moments.** Celebrations default to Calm, with simplified Fun effects that do not overlap.
