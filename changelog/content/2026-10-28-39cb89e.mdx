- **Collect files from a Punchcard folder.** Use a folder as the source for a workflow’s document group.

- **Manage request folders with CoAudit.** Create and rename folders from chat.

- **Celebrate completed request work.** Engagement success moments provide visual feedback as requests progress.

- **Find clients more smoothly.** Client lists load faster, and search selects the intended client without interrupting typing.
