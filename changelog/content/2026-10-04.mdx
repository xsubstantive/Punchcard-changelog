## Requests & Subrequests

- **Paste a table, get real subrequests.** Pasting rows under a request (or importing Excel/CSV) now creates one subrequest per row — each with its own status, assignee, due date, files, and comments — instead of a static selections grid. Choose **Show as: Table** (a compact row-per-item view inside the request) or **List** at any time, and switch later from the request's **⋯** menu without losing any data.
- **Edit values directly in the table.** Auditors can edit a subrequest's values inline, rename or remove a column across every row, and reorder or clear values. Clients can upload documents, comment, and submit each row for review, keeping updates organized line by line.
- **Download the table anytime.** The pasted table is available as a generated attachment on the request (Excel), and a **Sampling receipt** (Excel + PDF) remains available for tables created from a sampled list.
- **CoAudit can work with your tables.** Ask CoAudit to read a subrequest table, edit a value, add rows, or switch the view — changes appear immediately in the request.
- A **General** row inside the table keeps the request's own documents (not tied to a specific row) easy to find and upload to.
