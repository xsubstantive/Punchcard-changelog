## Features

- **Save chat files straight into an engagement.** Ask CoAudit to save a file from your conversation, whether CoAudit created it or you attached it, and it files the document into the engagement for you.
- **Choose the destination and folder.** Save into the engagement's own Files (your audit team's workspace) or into the documents of a specific Request. Name a folder path such as "Workpapers/Testing" and CoAudit uses it.
- **Folders created on request.** If the folder doesn't exist yet, ask CoAudit to create it as part of the save.
- **Create and file in one step.** Ask CoAudit to build a file, such as an Excel workbook, and save it into a folder in the same request. This also works for automated agent tasks.
- **Works across CoAudit.** Available on the web and in the Office panes.

## Improvements

- **Approval before clients see anything.** When a save is going into a Request, CoAudit shows an approval card naming the file first, since your client will see it. Saves into the engagement's own Files don't need approval.
- **No stray folders.** If a save can't go through, for example because the file isn't ready or has already been saved, no empty folders are left behind.
- **Existing safeguards still apply.** Folders that sync with OneDrive stay protected and can't be saved into, and CoAudit won't quietly file a document under a different folder name than the one you asked for.
- **Role-based availability.** The save option is offered only to team members who can manage engagements.
