## Requests

- **Simpler sub-request editing:** Editing a sub-request and adjusting its columns now takes fewer steps, with a cleaner menu and clear action icons.
- **Search in the toolbar:** In compact views, sub-request search now sits in the toolbar so it's always within reach.
- **Consistent request headers and related-task details:** Request headers and the properties shown for related tasks now look and behave the same way throughout.
- **Matching creation and relation menus:** Creating a task and linking related items use the same layout and icons, so they're easier to recognize.

## Folders

- **Better use of space in folder views:** Folder headings now use the room available, and the request title keeps its space before folder columns appear.
- **Clearer folder cells:** Cells with files are outlined, and empty cells and cells that still need files highlight on hover, so it's easier to see what's complete and what's missing.
- **Reserved folder names:** "Other" can no longer be used as a shared folder name, and "Tasks" can no longer be used as a top-level engagement folder name. This prevents two folders with the same name from appearing side by side.

## Files

- **Consistent drag-and-drop:** Dropping files looks the same for clients and auditors. The highlight appears when you drag files over a drop area and clears when you drag away.
- **Connected file drop areas and smoother client uploads:** Uploading files from the client side is more streamlined.

## Fixes

- Circular engagement header logos now fill their frame with no gap around the edge.
