## Excel add-in: Context tab and Browse files

- **Folders open in place.** Use the arrow at the start of a folder or request row to see what's inside without leaving the list. Clicking the row still opens it. Arrow keys work too: Right opens, Left closes.
- **Clearer Context list.** Files are grouped under two headings, **Requests** and **Engagement files**. "Client visible" now appears once inside a request, and only when a client can actually open it.
- **Select mode.** Choose several items at once and remove them from context or exclude them from Punchcard in a single step. Your selections stay put even when rows scroll off screen.
- **Browse files is calmer.** The window no longer shifts as you move between folders, shows the client's logo or initials beside the engagement name, and opens folders in place. Click a name to open it, tick the checkbox to select. Sort by and Order are now in a More menu.
- **Empty Context tab.** It's now a drop area: drag files onto the pane to add them.
- **Consistent wording.** The assistant is called **Punchcard** throughout the add-in; "Agent" is only the name of the tab.
- **Notifications at the bottom.** Messages no longer cover the top rows of your list or block a click.
- **Engagement picker.** The "All clients" row shows your firm's logo or initials.

## Selecting files in the web app

- **One way to select.** In a request's Files, the Files tab and the Library, click a file's name to preview it and click elsewhere on the row to select it. Cmd/Ctrl adds to the selection, Shift selects a range, and Cmd/Ctrl+A selects everything.
- **Select mode.** Choose Select from the menu for checkboxes, which is especially helpful on touch screens.
- **Move several files at once** from a request's Files.

## Search

- **Command menu search is scoped to your current engagement**, with "Requests in…" and "Files in…" sections and a Show all option. Typing an engagement's ID ranks that engagement first. Press Enter to preview a file, or Cmd+Enter to open its request.
- **Create group** is now available from the Create menu.
- **Request list search** looks inside comments, folder names and files, shows the matching words, and lists matching files under their request. The board stays a board while you search.

## Fixes

- Menus and tooltips in the Context tab no longer cover each other or block the next row's click.
- Escape now closes menus and dialogs in Excel for Mac.
- Requests in the Viewer's file picker are listed in number order (2 before 10).
- Reviewing an issue on a file inside an opened folder now shows all related files.
