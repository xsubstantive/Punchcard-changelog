### New

- **Add one subrequest at a time, instantly.** The "+" button on the Subrequests heading now opens the New Subrequest form directly, pre-filled with the same fields your other subrequests already use — just fill in the values and create it.
- **Edit subrequests as a table.** When a request's subrequests are organized as a table, the "⋯" menu now includes **Edit as table…**, letting auditors add, change, and delete subrequests together in one dialog. Paste a block of data from Excel or type new rows directly — pressing Enter moves down a column just like a spreadsheet.
- **Review before you save.** Before any table edit is applied, a review screen shows exactly what changed — new rows, updated values, and any subrequests that will be removed, including what they contain (such as uploaded files or comments) — so nothing is deleted by accident.

### Improved

- Deleting a subrequest that has files, comments, or an in-progress status now asks for an extra confirmation, and the Save button clearly states how many subrequests will be removed.
- Closing the table editor with unsaved changes now asks before discarding your edits.
- Subrequests entered as free text (just a title, no structured data) now display properly inside the subrequests table instead of being left out.
- A note now appears when there are more columns to see by scrolling sideways in the subrequests table.
