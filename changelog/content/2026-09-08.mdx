## Bug Fixes

- **Workpaper data source card actions restored**: The three-dot menu on data source cards — used to rename or delete a source — was not opening when clicked. This is now fixed; Rename and Delete work as expected again.
- **Chat rename shows a clear error when it fails**: Renaming a conversation via the three-dot menu now displays an error message if the title couldn't be saved, so you know to try again rather than assuming the change was applied when it wasn't.
